# 静态移植工作台

用户于 2026-11-12 将当前研发验收范围改为：不依赖 Windows SDK，继续静态编写整个 IINA 移植的 C++ 源码；本阶段不要求编译、测试或运行。目标代码量不得低于上游 Swift 文件数和代码行数。此变化不是对已实现或已验证状态的追认。

## 可复核统计口径

执行 `python3 scripts/porting-census.py`；加 `--json` 可获取逐文件明细。

- Swift 分母：固定快照 `references/iina/` 下全部 `.swift` 文件，包括 CLI、插件 CLI、Safari 扩展，**不悄悄缩减到播放器核心**。
- C++ 分子：`src/` 下产品 `.cpp/.h/.hpp`；“新建”以原始指定基线 `d64f404` 的路径集合为准。文件数与行数均只计算新增文件；旧文件新增行不用于抬高新建指标。
- 排除测试、第三方 mpv 头文件、生成文件、缓存和文档。不得复制 Swift 作为 C++ 注释或生成无意义空类充数。
- 物理行和非空行分别报告。物理行包含正常注释与空行；它不是语义代码行，也不证明功能覆盖或质量。逐文件清单便于审阅是否存在人为扩行。
- 原始 Swift：208 文件，61,220 物理行，53,375 非空行。数量目标目前**未达到**。

模块是否“写完”须同时看业务入口、状态、错误、资源、平台适配、实际调用方和来源映射；不能靠文件存在认定完成。以下不是全量完成清单。

全量移植仍需跨模块持续开发，包括偏好默认值/存储与迁移、滤镜状态投影、菜单快捷键、自动文件匹配、网络及字幕提供商、插件运行时与权限模型、窗口与绘制交互、错误与日志等。语言转换不能替代这些实现决策。当前不存在可据以宣称“完整 IINA 已移植”的证据。

## 本批验证口径

按最新要求未执行编译、自动化测试、应用运行或 SDK 验证；只阅读源代码和接口、人工静态审阅、统计与 Git 发布核验。仓库中早先测试通过的记录只覆盖当时提交，不自动覆盖本批新增代码。Windows 构建、音视频运行、滤镜与硬件互操作仍待后续独立验收。

## 全量文件级工作队列

`docs/PORTING-INVENTORY.json` 对固定快照的全部208个Swift文件列出逐文件行数、现有审阅入口和保守覆盖状态。使用 `python3 scripts/porting-inventory.py > docs/PORTING-INVENTORY.json` 更新。`partial-static-unverified` 不是“文件移植完成”；`not-mapped` 也不是断言完全没有相关行为，而是尚未记录可复核映射。这样不会因已有一部分 PlayerCore 代码就将数千行源文件全部计为完成。

第四批已补齐部分先前缺失接线：批量队列计划的异步执行器，排序/清空/shuffle界面；原生M3U8保存、网络打开、OSD基础状态投影、CompactOverlay、AB/帧步进，以及同目录字幕匹配。较早表格描述其批次当时的边界，最新以PORTING.md各后续批次为准。构建生成物排除不包含真实源目录的可再生协议常量声明；其重复索引`.inc`单独保留且不计入`.cpp/.h/.hpp`指标。数量依然不证明语义覆盖。

第五批新增实际快捷键配置/路由、schema 偏好编辑与持久化、异步截图保存和剪贴板后处理。窗口失焦/最小化自动暂停政策尚未接入；多配置命名管理、任意 mpv 脚本兼容、截图预览仍不是已完成功能。新增模型仅在文档列出的适配器接线范围内计为静态实现，不能升级为运行验证。

第六批将窗口失焦/最小化暂停政策接入实际原生事件与会话回复；扩展SMTC时间线、历史浏览移除撤销、媒体信息和音频输出设备。第五批所述“窗口暂停政策未接线”仅代表当时状态。当前仍未实现硬件睡眠/显示设备恢复、完整Inspector任意属性、在线字幕服务、插件运行时、完整多窗口与缩略图生成预览等；最新源码范围见PORTING第六批。

第七批接入 vf/af 当前滤镜链编辑与本地悬停缩略图。滤镜节点保留未知字段，编辑有新鲜快照保护但不是CAS；缩略图使用Windows Media Foundation/WIC按需解码，不等价于上游FFmpeg全格式/全片预生成，磁盘缓存及保存滤镜管理仍未完成。仅静态实现，未编译运行。
